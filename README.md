# Análise de Chamados de Service Desk com Python
##  Contexto
Este projeto simula a análise de dados de uma operação de Service Desk, com o objetivo de identificar padrões de incidentes, avaliar prioridades e otimizar o processo de atendimento com base em dados.

Analisar dados de chamados para identificar padrões, prioridades e oportunidades de melhoria no processo de atendimento.

# Ferramentas utilizadas
Python (pandas)
Google Colab
Matplotlib

# Principais análises
Distribuição de chamados por categoria
Análise de prioridade dos incidentes
Tempo médio de resolução
Cruzamento entre categoria e prioridade

# Insights
- A categoria **Sistema** concentra o maior volume de chamados, indicando possíveis falhas recorrentes ou necessidade de melhorias estruturais
- Chamados de **Alta prioridade** apresentam menor tempo de resolução, indicando alinhamento com boas práticas de SLA
- As categorias **Acesso** e **Rede** concentram maior número de incidentes críticos, sugerindo impacto direto na operação dos usuários

Conclusão
A análise demonstra que a priorização de chamados está sendo realizada de forma eficiente, respeitando o nível de criticidade dos incidentes. Além disso, identifica oportunidades de melhoria em categorias com maior volume de ocorrências.

## Valor para o negócio

A análise permite identificar pontos críticos na operação de suporte, priorizar melhorias em sistemas e otimizar o tempo de resposta, contribuindo diretamente para a eficiência operacional e satisfação do usuário.
